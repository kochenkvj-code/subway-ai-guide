# V2 model/token comparison lab

URL: /search-lab/v2-comparison, linked from existing Search Lab. Existing Search Lab UI/API and V2 production generation settings remain unchanged. The isolated endpoint /api/search-lab/v2-comparison uses current V2 policy/entry station validation and the identical current system/grounded payload (covered by fixture comparison). Supported variants are server allowlisted: current Flash-Lite 500 default thinking, A Flash-Lite 1200 default thinking (documented default MINIMAL), B Flash-Lite 1200 LOW, C Flash 1200 LOW. No arbitrary model/token values are accepted. Default thinking remains omitted in both current and A to isolate the cap change.

No calls run on page load. Default is current+A, one round, two paid generation/search requests on explicit execution. Users can select settings and 1/3/5 repeats. Requests are sequential and order rotates per round. Each call starts without conversation history. UI shows browser/handler time, finishReason, nullable prompt/answer/thought/total token counts, answer, menu, actual returned search queries, sources, search suggestions and expandable JSON. Even empty generated output retains diagnostics for token-limit investigation. Export includes completed result records with question/station/language/round/config. Errors remain per-result, not silently discarded. Medians and maximum observed time are exploratory, not statistical latency guarantees. Google-rendered suggestions are preserved.

Abort requests cancel the client sequence and signal the server/provider; this does not guarantee cancellation of already-started billable work. No retries are performed. Existing deployment protection/public lab access conventions are retained; no admin secret is exposed or environment settings changed.

Validation: build; comparison fixture tests verify baseline request equality, exact model/cap/LOW changes, invalid settings before provider access, absent metadata remaining null and empty answer diagnostics. Browser fixtures verify no auto calls, explicit two requests, station presets, diagnostics and 320/390/768px layouts. No paid Gemini call executed by the agent. Availability, actual accuracy, latency, token-limits/thinking interaction and billing must be measured by explicit user execution. Query/source metadata alone does not establish original source evidence or truth.
