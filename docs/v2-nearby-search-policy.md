# V2: nearby alternatives without merging station ownership

The station-code/line identity policy remains. Ownership is distinct from search coverage and transfer accessibility. The grounded prompt now considers entry-station facilities, connected arcades/buildings, transfer-connected other-line stations and nearby public/commercial alternatives. These are relevance priorities, not four mandatory sequential searches or extra model calls. External venue results need not mention a subway line to be relevant; their ownership/category must be identified.

Optional leads are keyed by station code in station-search-hints.js. 0154 gets Jong-o shopping centre and Jongno 5-ga underground arcade aliases; 0159 and 2637 get their other-line Dongmyo counterpart. Other stations have no added leads. No nursing-room presence, floor, exit, operating status or route is hardcoded. Current search evidence must verify those claims. Jong-o relationship source checked during implementation: https://www.sisul.or.kr/open_content/undershop/guide/jongno/jongo.jsp (Seoul Facilities Corporation describes it as a Jongno 5-ga-linked shopping arcade).

Recommendation instructions now require practical additional menu detail, not mere topical relevance. Unknown detail availability means no facility recommendation. Answers directing to an external mall/outside venue/other-line facility should omit the entry-line facility button. This remains a model instruction, not a semantic guarantee enforced by a menu ID parser.

Comparison: prior line-qualified ownership search is retained but explicitly broadened for useful alternatives. The old generic arcade policy lacked named entry-station leads and did not require considering alternatives before staff referral. The updated prompt adds those leads and requires useful alternatives to be described by category, with verified location details only. Existing language, bounded history, sources, one generation call and legacy/Search Lab isolation remain.

Verification: prompt/provider-fixture tests compare required clauses and station-specific leads for Jongno 5-ga, Dongmyo 1/6, and unconfigured Jonggak; existing baseline-payload tests verify legacy provider requests remain identical.
