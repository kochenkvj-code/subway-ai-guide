# V2 gate UX copy

Only embedded V2 gate views use the new writing overrides. The live `/` menu, guides and action copy remain identical to commit 1d970d0, including its existing E-33/E-44 text. Operational guidance is preserved from that latest baseline: V2 E-03/E-04/E-05 continue to describe station-office visits as conditional, and are not changed into mandatory visits.

The V2 picker uses a two-step instruction and clearer error names in Korean, English, Japanese and Chinese. E-33/E-44 show the already-processed/no-extra-fare explanation separately from the two numbered actions. Their second action says to pass through the wide gate even if it beeps. The added stop/turn-back instruction was removed from V2 per user correction; the live version remains unchanged. Other passage instructions, top-up steps, diagram links and captions are shortened. The current location diagram, navigation, feedback and chat behavior are retained.

Validation: `npm run build`; `node tests/v2-gate-writing-ui.cjs`. The browser test covers eight errors in four languages at 390x844 and 320x640, error preservation on language changes, and V1 isolation. It compares live copy constants against the pre-change baseline and verifies that all bottom actions fit inside the chat viewport at 390x844. Statistics and arrival requests are stubbed; no production records are written. `node tests/gate-chat-history-ui.cjs` checks that gate/chat history preservation still works in V1.
